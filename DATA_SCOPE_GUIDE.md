# Data Scope Clarification Guide

## Overview

This dashboard is designed for **Dayforce executives** to make strategic decisions based on customer feedback. Each page has a specific focus - some are Dayforce-only, others compare Dayforce with competitors, and some show market-wide data depending on your filter selection.

## Visual Indicators

### Dashboard Header

At the top of every page, you'll see two banners:

1. **Data Source Banner** (Blue/Green)
   - Shows whether you're using Synthetic or Real data
   - Displays total review count

2. **Filter Scope Banner** (Green/Yellow/Red)
   - 🎯 **Green**: Dayforce Only - All insights are Dayforce-specific
   - 📊 **Yellow**: Dayforce + Competitors - Mixed data, use caution
   - ⚠️ **Red**: Competitors Only - No Dayforce data (adjust filters)

### Page-Specific Indicators

Each tab includes clear indicators showing what data is being analyzed.

## Page-by-Page Breakdown

### 1. 🎯 Dayforce Focus
**Scope:** Always Dayforce-only with competitive benchmarks

**What You See:**
- Dayforce performance across all 5 dimensions
- Market comparison showing Dayforce vs. average competitor
- Dayforce-specific pain points, strengths, and gaps
- Customer segment analysis for Dayforce only

**Data Clarity:**
- Header states: "Dayforce Strategic Intelligence"
- All metrics clearly labeled as Dayforce vs. Market/Competitors
- Competitive context is for benchmarking only

**Use This When:** You want pure Dayforce insights with competitive context

---

### 2. 📈 Executive Summary
**Scope:** Depends on sidebar filter selection

**What You See:**
- Metrics for ALL products currently in your filter
- If only Dayforce is selected: Shows Dayforce performance
- If multiple products selected: Shows aggregate/comparison data

**Data Clarity:**
- Banner at top shows which products are included
- ✅ "Viewing: Dayforce Only" = Dayforce-specific
- ⚠️ "Viewing: 5 Products" = Market-wide data (not Dayforce-specific)

**Use This When:** 
- Dayforce only: Executive overview of Dayforce performance
- Multiple products: Market landscape and competitive comparison

**Important:** Use sidebar "Products" filter to control scope

---

### 3. 🎯 Sentiment Analysis
**Scope:** Depends on sidebar filter selection

**What You See:**
- Deep-dive into dimensions for selected products
- "Compare with Competitors" checkbox changes view:
  - Unchecked: Single product analysis (can be Dayforce)
  - Checked: Multi-product comparison

**Data Clarity:**
- Banner shows: "Analyzing: Dayforce Only" or "Analyzing: 5 Products"
- Each chart title specifies scope
- Comparison mode explicitly labels each product

**Use This When:**
- Understanding Dayforce dimension performance (filter to Dayforce only)
- Comparing Dayforce vs specific competitor (enable comparison)

**Important:** Always check the banner to confirm scope

---

### 4. 💡 Topic Intelligence
**Scope:** Defaults to Dayforce, user-selectable

**What You See:**
- **Primary Focus dropdown** - Select which product to analyze
- **Enable Comparison checkbox** - Compare two products side-by-side
- Default is Dayforce-only analysis

**Data Clarity:**
- Info banner: "This page defaults to Dayforce analysis"
- Success banner: "Analyzing: Dayforce Only (40 reviews)"
- Comparison banner: "Comparison Mode Active: Dayforce vs. Workday"
- Review browser clearly shows product for each review

**Use This When:**
- Understanding what Dayforce customers discuss (default)
- Comparing Dayforce topics vs competitor topics (comparison mode)
- Browsing specific product reviews (use product filter)

**Important:** This is the most flexible page - always check which product is selected

---

### 5. ⚔️ Competitive Insights

**What You See:**
- Radar charts comparing Dayforce vs. competitors
- Head-to-head comparison (select specific competitor)
- Competitive scorecard showing all products

**Data Clarity:**
- Header: "Focus: Dayforce vs. Market"
- Dayforce is always highlighted in charts (thicker lines, special colors)
- Each comparison explicitly names products
- Scorecard shows all products but emphasizes Dayforce position

**Use This When:** Benchmarking Dayforce against competition

**Important:** This page always includes competitors for context

---

### 6. 🎬 Action Recommendations
**Scope:** Always Dayforce-only

**What You See:**
- Strategic priorities for Dayforce
- Dayforce pain points and quick wins
- Improvement opportunities for Dayforce

**Data Clarity:**
- Header: "Data-driven insights to drive strategic improvements for Dayforce"
- Info banner: "Focus: Dayforce - All recommendations are specific to Dayforce"

**Use This When:** Identifying actionable improvements for Dayforce

**Important:** This page ONLY analyzes Dayforce data

## How to Control Data Scope

### Sidebar Filters

**Products Filter:**
- "All" = All products (Dayforce + 4 competitors)
- Select only "Dayforce" = Dayforce-exclusive view
- Select multiple = Comparative view

**Impact on Pages:**
- **Dayforce Focus**: Always Dayforce (ignores filter)
- **Executive Summary**: Respects filter
- **Sentiment Analysis**: Respects filter
- **Topic Intelligence**: Independent product selector
- **Competitive Insights**: Always comparative
- **Action Recommendations**: Always Dayforce (ignores filter)

### Best Practices

1. **For Dayforce-Only Insights:**
   - Select only "Dayforce" in sidebar Products filter
   - Or use Dayforce Focus / Action Recommendations tabs

2. **For Competitive Analysis:**
   - Keep multiple products selected
   - Use Executive Summary, Sentiment Analysis, or Competitive Insights

3. **For Topic Comparison:**
   - Use Topic Intelligence page
   - Select products within the page (independent of sidebar)

4. **Always Check:**
   - Dashboard header banner (shows current filter scope)
   - Page-specific indicator (shows what that page is analyzing)

## Common Scenarios

### "I want to see only Dayforce performance"
1. Sidebar → Products → Select only "Dayforce"
2. Dashboard banner shows: 🎯 "Dayforce Only"
3. Go to any tab - all show Dayforce data

### "I want to compare Dayforce to Workday"
**Option 1: Using Sidebar**
1. Sidebar → Products → Select "Dayforce" and "Workday"
2. Use Sentiment Analysis or Competitive Insights

**Option 2: Using Topic Intelligence**
1. Topic Intelligence tab
2. Primary Focus → Dayforce
3. Enable Comparison → ✓
4. Compare With → Workday

### "I want to see the entire market landscape"
1. Sidebar → Products → "All"
2. Dashboard banner shows: 📊 "Dayforce + 4 Competitors"
3. Executive Summary shows market overview
4. Competitive Insights shows full benchmarking

### "I'm not sure what I'm looking at"
**Check these in order:**
1. Dashboard header banner (top of page)
2. Page-specific indicator (under page header)
3. Chart/section titles (should specify scope)
4. Hover over metrics (tooltips may provide context)

## Tips for Decision-Making

### Strategic Planning
- Use **Dayforce Focus** for pure Dayforce insights
- Use **Action Recommendations** for improvement priorities
- Use **Competitive Insights** to understand market position

### Sales Enablement
- Use **Competitive Insights** → Head-to-Head for battle cards
- Use **Topic Intelligence** → Comparison mode for differentiators
- Filter to specific competitor for targeted analysis

### Product Roadmap
- Use **Action Recommendations** for priority matrix
- Use **Sentiment Analysis** (Dayforce only) for dimension deep-dives
- Use **Topic Intelligence** → Dayforce to understand customer priorities

### Customer Success
- Use **Dayforce Focus** → Pain Points for at-risk customers
- Use **Sentiment Analysis** by segment (filter sidebar)
- Use **Topic Intelligence** → Review Browser for specific feedback

**Remember:** When in doubt, look for the colored banner indicators at the top of the dashboard and under each page header. They always tell you exactly what data you're viewing.
