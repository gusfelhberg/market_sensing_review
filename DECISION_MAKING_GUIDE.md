# How to Make Strategic Decisions with the Dayforce Dashboard

## Quick Decision-Making Guide

### 1. Daily/Weekly Check (5 minutes)

**Goal:** Stay informed on current position

**Steps:**
1. Open dashboard → **Dayforce Focus** tab
2. Look at the 5 dimension cards at top:
   - 🏆 Leading = Celebrate, maintain
   - ✅ Above Market = Good, optimize
   - ⚡ At Par = Watch closely
   - 🎯 Opportunity = **Take action**

3. Check Key Insights sidebar:
   - Is trend 📈 Improving or 📉 Declining?
   - Are we above or below market overall?

4. Scan "Where We Trail" section:
   - Any red cards (gap > 0.3)? → Urgent
   - Any yellow cards? → Important

**Decision Output:** 
- Which dimension needs immediate attention?
- Is our position improving or deteriorating?

---

### 2. Identify Top 3 Priorities (15 minutes)

**Goal:** Focus resources on highest-impact areas

**Steps:**
1. In **Dayforce Focus** tab → Click **Pain Points** sub-tab
2. Count red cards (🔴 Critical issues)
3. Read top 3 critical pain points
4. Note which dimension each relates to

5. Go back to main view
6. Compare pain point dimensions with "Where We Trail"
7. Identify overlap = **Highest Priority**

**Decision Output:**
Priority list with:
- Dimension name
- Gap size vs market
- Number of critical pain points
- Customer impact level

**Example:**
```
Priority 1: Implementation (Gap: -0.3, Critical issues: 5)
Priority 2: Product Reporting (Gap: -0.2, Critical issues: 3)
Priority 3: Mobile Experience (Gap: -0.15, Critical issues: 2)
```

---

### 3. Learn from Competitors (20 minutes)

**Goal:** Understand what "good" looks like

**Steps:**
1. Select your #1 priority dimension
2. Go to **Competitive Gaps** sub-tab
3. Expand the gap for your priority dimension
4. Read 2-3 competitor review examples
5. Note what customers praise about competitor

6. Go to **Action Recommendations** tab
7. Find recommendations for that dimension
8. Compare with what competitor does well

**Decision Output:**
- Specific features/approaches competitors use
- Customer expectations in that dimension
- Gap between current state and desired state
- Inspiration for improvement roadmap

**Example:**
```
Learning from UKG Pro on Implementation:
✓ They have structured 12-week methodology
✓ Dedicated implementation manager per customer
✓ Weekly status calls with clear milestones
✓ Pre-configured templates for common scenarios

Dayforce Current State:
✗ Variable timeline (6-12 months)
✗ Shared resources across projects
✗ Ad-hoc communication
✗ Heavy customization required

Action: Adopt structured methodology, hire dedicated PMs
```

---

### 4. Deep Dive on Critical Issue (30 minutes)

**Goal:** Understand root cause and solution path

**Steps:**
1. Pick one critical pain point from Priority 1
2. Read the full feedback
3. Check review date and customer profile
4. Is this recent? Is it a pattern?

5. Go to **Topic Intelligence** tab
6. Search for related topic (e.g., "Reporting")
7. Click **Topic Deep Dive** → Select the topic
8. Review sentiment scores by dimension
9. Read sample reviews mentioning this topic

10. Go to **Sentiment Analysis** tab
11. Select the dimension (e.g., Product)
12. Set filter to "Lowest Score"
13. Read detailed reviews to understand context

**Decision Output:**
- Root cause of the issue
- How widespread is it? (% of reviews)
- Which customer segments affected most?
- Specific examples to share with product team
- Estimated impact on overall sentiment

---

### 5. Build Action Plan (45 minutes)

**Goal:** Create executable improvement plan

**Steps:**
1. Open **Action Recommendations** tab
2. Review the Priority Matrix
3. For each opportunity, note:
   - Current score
   - Target score
   - Gap
   - Affected reviews

4. Click expand on top priority
5. Review recommended actions
6. Assess each action:
   - Feasibility (Can we do it?)
   - Timeline (How long?)
   - Impact (Will it move the needle?)
   - Cost (Resources needed?)

7. Create 90-day action plan:
   - Quick wins (< 4 weeks)
   - Medium-term (4-8 weeks)
   - Strategic (8-12 weeks)

8. Assign owners to each action
9. Set metrics to track progress

**Decision Output:**
90-Day Action Plan template:

```markdown
## Priority: Implementation (Score: 3.8, Target: 4.2)

### Quick Wins (< 4 weeks)
- [ ] Create implementation timeline template
- [ ] Improve project kickoff process
- [ ] Weekly customer check-in protocol
Owner: [Name], Impact: +0.1, Cost: Low

### Medium-Term (4-8 weeks)
- [ ] Develop implementation playbooks
- [ ] Certification program for consultants  
- [ ] Customer communication dashboard
Owner: [Name], Impact: +0.2, Cost: Medium

### Strategic (8-12 weeks)
- [ ] Redesign onboarding methodology
- [ ] Hire 3 dedicated implementation PMs
- [ ] Build customer success platform
Owner: [Name], Impact: +0.3, Cost: High

Success Metric: Implementation score 4.0+ by Q2
Track: Weekly review count & avg score
```

---

### 6. Monitor Progress (Monthly)

**Goal:** Validate improvements are working

**Steps:**
1. Filter dashboard to last 30 days
2. Compare to previous 30 days
3. Check if priority dimensions improving

4. Go to **Dayforce Focus** → Main view
5. Check recent trend indicator
6. Has it changed from last month?

7. Go to **Pain Points** tab
8. Are critical issues decreasing?
9. Are new pain points appearing?

10. Document progress:
    - Score changes by dimension
    - New vs resolved pain points
    - Competitive gap changes

**Decision Output:**
Monthly scorecard:
```
Implementation Progress (Month 2 of 90-day plan)

Score Movement: 3.8 → 3.9 (+0.1) ✓ On track
Critical Pain Points: 5 → 3 (-2) ✓ Improving
Competitive Gap: -0.3 → -0.25 (+0.05) ✓ Narrowing

New Issues Emerging:
- Mobile app mentioned more (watch)

Continue Actions:
✓ Playbook rollout
✓ Consultant training

Adjust:
⚠️ Add mobile app to Q2 roadmap
```

## Decision Frameworks

### Framework 1: Triage System

**Red (Act Now):**
- Gap > 0.3 vs market
- 5+ critical pain points
- Declining trend
→ **Action:** Emergency task force, executive attention

**Yellow (Plan Action):**
- Gap 0.1-0.3 vs market
- 2-4 critical pain points
- Stable trend
→ **Action:** Include in quarterly roadmap

**Green (Monitor):**
- Leading market or small gap
- 0-1 critical pain points
- Improving trend
→ **Action:** Maintain, share best practices

### Framework 2: Impact vs Effort Matrix

**High Impact, Low Effort** (DO FIRST):
- Quick wins from Action Recommendations
- Low-hanging fruit pain points
- Process improvements

**High Impact, High Effort** (STRATEGIC):
- Major competitive gaps
- Platform improvements
- Organizational changes

**Low Impact, Low Effort** (FILL-IN):
- Nice-to-have improvements
- Polish existing features

**Low Impact, High Effort** (AVOID):
- Defer or cancel
- Not worth resources

### Framework 3: Customer Impact Assessment

**Critical (Affects retention):**
- Implementation failures
- Product doesn't work as expected
- Support is unresponsive
→ **Action:** Immediate fix, executive escalation

**Important (Affects satisfaction):**
- Missing features
- UX friction
- Slow performance
→ **Action:** Prioritize in roadmap

**Nice-to-have (Affects delight):**
- Extra features
- Enhanced UI
- Advanced capabilities
→ **Action:** Backlog for future

## Common Decision Scenarios

### Scenario 1: Budget Allocation for Next Quarter

**Question:** Where should I invest $500K?

**Process:**
1. Check **Dayforce Focus** → Identify top 2 gaps
2. Go to **Action Recommendations** → Review recommendations
3. Estimate costs for each action
4. Calculate ROI = (Gap size × Review volume × Customer value)
5. Allocate to highest ROI items

**Example Decision:**
- 60% to Implementation improvements (biggest gap)
- 30% to Product/Reporting enhancements
- 10% to maintain strengths (Payroll)

### Scenario 2: Competitive Sales Situation

**Question:** Competitor in sales deal, how do I position?

**Process:**
1. **Competitive Insights** tab → Head-to-Head comparison
2. Select Dayforce vs Competitor
3. Note dimensions where Dayforce leads
4. Go to **Dayforce Focus** → **Strengths** tab
5. Get specific customer quotes

**Example Decision:**
Sales talking points vs Workday:
- Lead in: Workforce Management, Payroll
- Match in: Customer Experience
- Trail in: UX (acknowledge, show roadmap)
- Unique: Single database (they can't match)

### Scenario 3: Product Roadmap Prioritization

**Question:** What features to build next year?

**Process:**
1. **Topic Intelligence** → Trending topics
2. Filter to Dayforce reviews only
3. Identify topics with low sentiment
4. Cross-reference with **Pain Points**
5. Check **Competitive Gaps** for validation

**Example Decision:**
Top roadmap priorities based on data:
1. Reporting/Analytics (12 critical mentions, gap vs Workday)
2. Mobile App (8 critical mentions, customer expectation)
3. Integrations (6 mentions, competitive disadvantage)

## Tips for Effective Use

✅ **Do:**
- Review dashboard weekly
- Share insights with teams
- Track changes over time
- Act on critical pain points within 30 days
- Celebrate improvements

❌ **Don't:**
- Make decisions on single review
- Ignore competitive context
- React to every complaint
- Forget to monitor progress
- Focus only on weaknesses

**Remember:** This dashboard turns customer voice into executive intelligence. The goal is not just to see the data, but to **make better, faster decisions** that improve customer satisfaction and competitive position.
